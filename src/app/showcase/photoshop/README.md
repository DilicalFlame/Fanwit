# Photoshop showcase

A rough copy of Photoshop, built only from layout primitives and mock views.

Options bar in the `header` region, a tool strip as a narrow sidebar, documents as tabs, and groups of tabbed panels docked in a split.

Apply it from View > Layout preset. Strip it with `pnpm fw strip showcase-photoshop` and bring it back with `pnpm fw restore showcase-photoshop`.
