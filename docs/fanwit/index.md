# Welcome

FaNWiT is a template for desktop apps that also run on the web: a Svelte interface, a Rust core, and everything an app needs before its first feature (commands, shortcuts, menus, layouts, windows, settings, themes, plugins, an installer and this manual).

This manual is written at three levels. Pick the one that matches what you know today; the switch in the title bar changes what the contents show, and every page you finish is ticked off.

<Levels />

Looking up one command, setting, file format or function? **Reference** in the title bar lists all of them, generated from the code, and the search box (<Keys keys="/" />) finds any page, section or symbol.
