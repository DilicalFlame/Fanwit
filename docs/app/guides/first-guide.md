# Your first guide

A good guide answers three questions, in this order:

1. **Why** does this feature exist, and when should I reach for it?
2. **How** do I use it, step by step?
3. **What** happens under the hood, so I can predict what it does next time?

<Callout kind="why">

Readers who know why a feature works the way it does can work out the details themselves. `pnpm fw docs check` asks every guide for one of these boxes, so the reason is never skipped.

</Callout>

Readers can run commands straight from the page:

```fanwit-run
theme.select
```

Show a shortcut that is always current (<Keys command="palette.open" />), number your steps with `<Steps>`, and see every component in the FaNWiT manual's **Manual and docs** guide.

Link to other pages with `manual://app/welcome`, and to the FaNWiT manual with `manual://fanwit/guides/commands`: [Welcome](manual://app/welcome).
