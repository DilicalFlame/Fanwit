# Welcome

This is your app's manual. It lives in `docs/app/` and ships with production builds, so your users can press **F1** to read it.

Replace this page with an introduction to your app: what it is for, and the one thing a new user should try first.

## Where things go

| Page | Put it in |
|---|---|
| First steps and tutorials | `section: Getting started` |
| Task oriented guides | `section: Guides` |
| Lookup tables | `kind: reference` |

The **Commands**, **Keybindings** and **Settings** pages under Reference are generated from your modules, so they are never out of date. Choose which ones appear with `reference` in `docset.toml`.
