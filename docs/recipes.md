# Recipes

## Figma style colour menu

Declare the location `canvas/selection`, add a `color-swatches` item that runs `canvas.setFill` with `{ color }`, and a `slider` whose `preview` command updates while dragging. The Menu Lab is this recipe.

## Notes app in one hour

Vault mode, a Markdown editor view that opens `.md` files, the Explorer, quick open, and a daily note command. The sample `notes` module is this recipe.

## Tray utility

Global data mode, the tray menu, a quick capture window kind and a global shortcut. Quick capture appends to Inbox.md through `capture.append`, so it is scriptable too.

## CLI first tool

Commands with `cli: true` and `--json` output; the GUI is an optional viewer.
